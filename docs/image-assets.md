# RANKOVA 이미지 교체

파일은 프로젝트의 `public/images/` 아래에 둡니다.

| 위치 | 파일명 | 권장 규격 | 제작 기준 |
| --- | --- | --- | --- |
| 헤더 심볼 | `rv-symbol.svg` | 정사각형 viewBox, 투명 배경 | 현재 포함된 임시 RV 심볼을 최종 로고로 덮어씁니다. 헤더는 28px로 표시합니다. |
| 홈페이지 오른쪽 | `rankova-home-hero.webp` | 1920 × 1080 WebP | 경쟁전 e스포츠 키 비주얼. 피사체 중심을 오른쪽에 배치하고 텍스트를 이미지에 넣지 않습니다. |
| 발로란트 전용 페이지 | `valorant-service-hero.webp` | 1600 × 900 WebP | 블랙·레드 키 아트. 주요 피사체를 오른쪽에 배치합니다. |
| 오버워치 2 전용 페이지 | `overwatch-2-service-hero.webp` | 1600 × 900 WebP | 블랙·오렌지 키 아트. 주요 피사체를 오른쪽에 배치합니다. |

배너 파일이 없으면 기존 홈 도형과 게임별 타이포그래피가 표시됩니다. 파일을 추가하거나 교체한 뒤 개발 서버를 다시 시작하고 새로고침합니다. 프로덕션에서는 파일을 포함해 다시 빌드합니다. 게임 키 아트는 사용 권한을 확보한 파일을 사용합니다.
